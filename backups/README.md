# نسخ احتياطية — رزق

## آخر نسخة = نفس GitHub `main`

| ملف | المعنى |
|-----|--------|
| `LATEST-GITHUB-BACKUP.json` | بيانات النسخة (commit، التاريخ، المصدر) |
| `LATEST-GITHUB-BACKUP.tar.gz` | أرشيف الكود المطابق لذلك الـ commit |
| `*.sha256` | بصمة التحقق من الأرشيف |

عند العمل من **الهاتف** تُحدَّث هذه الملفات بعد كل دمج مهم إلى `main`.  
عند فتح **الكمبيوتر**: انسخ `LATEST-GITHUB-BACKUP.tar.gz` (+ الـ JSON) إلى تخزينك المحلي كنسخة احتياطية أخيرة.

بيانات التشغيل المشفّرة (قاعدة/ملفات): `../rizq-backend/backups/`.
