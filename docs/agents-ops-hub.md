# مركز تسيير الوكلاء (Admin)

لوحة واحدة في لوحة التحكم لتفعيل/إيقاف عائلات الوكلاء، مراقبة الصحة، ومراجعة الأسئلة الفائتة.

## أين؟

لوحة الأدمن → **الوكلاء الذكيون → مركز تسيير الوكلاء**

## ماذا يفعل الأدمن؟

1. يرى حالة Claude / السر المشترك / فيسبوك / عدد الأسئلة الفائتة
2. يفعّل أو يوقف: الويدجت، عقل القنوات، الماسية، التسويق، الرد التلقائي، الاستثمارات، تسجيل الجودة
3. يفتح لوحات التفاصيل (مدير رزق، تسويق، مراقب…)
4. يراجع آخر الأسئلة الفائتة ويمسح السجل

## API

| Method | Path | وصف |
|--------|------|-----|
| GET | `/api/admin/agents-ops` | ملخص المركز |
| PATCH | `/api/admin/agents-ops` | حفظ التفعيل |
| GET | `/api/admin/agent-misses` | قائمة الفوائت |
| DELETE | `/api/admin/agent-misses` | مسح الفوائت |
| POST | `/api/agent/miss` | تسجيل فائت من الواجهة |

المصادقة: `x-admin-token` (ما عدا POST العام المحدود المعدل).
